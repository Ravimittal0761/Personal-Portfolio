About

Junior on paper, full‑stack in practice.

I'm an entry-level React Native developer who treats every side project like a real product brief: a working app, a sensible API behind it, and a UI someone would actually trust. My portfolio is built from apps that mirror real Indian consumer use cases — matrimony, dating, astrology, beauty bookings, food delivery — because that's the fastest way I know to learn product thinking, not just syntax.

I'm currently looking for remote internship or junior developer roles where I can keep shipping React Native and React apps, plug into real backends, and grow alongside a product team.
